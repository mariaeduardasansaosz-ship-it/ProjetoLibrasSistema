Projeto Libras Sistema
Sistema desenvolvido em Java Swing com integração ao banco de dados MySQL para gestão de propostas e serviços.
Título do Projeto: Projeto Libras Sistema 
Status do Projeto: Em desenvolvimento
Tecnologias Aplicadas:
•	Linguagem de Programação Java
•	Interface Gráfica Java Swing
•	Banco de Dados MySQL (Schema: sistemalibras)
•	Conectividade JDBC (MySQL Connector J)
•	Versionamento com Git e GitHub
Objetivo do Software: O software serve como um sistema de gestão e automação para a plataforma Libras, permitindo o controle de acessos de usuários, 
gestão de fornecedores e organização de fluxos comerciais. O foco é garantir a integridade dos dados através da integração direta com um banco de dados relacional.
Funcionalidades do Sistema (Requisitos):
•	Sistema de Login: Autenticação segura consultando a tabela de usuários no MySQL.
•	Controle de Perfis: Diferenciação de permissões para perfis específicos (como Administrador e Financeiro).
•	Gestão de Fornecedores: Tela dedicada para o cadastro e manutenção de parceiros comerciais.
•	Conectividade: Módulo de conexão robusto (ModuloConexao.java) para comunicação em tempo real com o banco de dados.
•	Interface Swing: Navegação entre telas (JFrame) organizada e intuitiva.
